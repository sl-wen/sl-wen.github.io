# 增强版俯视角RPG游戏功能文档

## 🎮 游戏概述

这是一个基于 Phaser 3 和 React 的增强版俯视角RPG游戏，参考了 [top-down-react-phaser-game](https://github.com/blopa/top-down-react-phaser-game) 项目，并添加了大量新功能和系统。

## ✨ 新增功能特性

### 🎒 物品系统 (Inventory System)

#### 功能特点
- **背包管理**: 20个槽位的背包系统
- **物品分类**: 武器、护甲、消耗品、材料、任务物品
- **堆叠系统**: 支持物品堆叠，提高背包效率
- **装备系统**: 武器、护甲、饰品三个装备槽位
- **物品效果**: 消耗品提供临时或永久属性加成

#### 物品类型
- **武器**: 木剑、铁剑、钢剑等，提供攻击力加成
- **护甲**: 皮甲、铁甲等，提供防御力和生命值加成
- **消耗品**: 生命药水、魔法药水、力量药水等
- **材料**: 草药、铁矿、金矿等，用于制作和任务
- **任务物品**: 古老钥匙、水晶碎片等特殊物品

#### 使用方法
- 按 `I` 键打开背包界面
- 点击物品查看详情
- 右键使用消耗品或装备物品
- 拖拽物品进行整理

### 📋 任务系统 (Quest System)

#### 功能特点
- **任务类型**: 主线任务、支线任务、日常任务、周常任务
- **任务目标**: 击杀、收集、对话、探索等多种目标类型
- **任务链**: 支持前置任务和任务依赖关系
- **进度跟踪**: 实时显示任务完成进度
- **奖励系统**: 经验值、金币、物品奖励

#### 任务示例
1. **第一步** (主线任务)
   - 目标: 与村长对话
   - 奖励: 50经验值、25金币、木剑

2. **草药收集** (支线任务)
   - 目标: 收集10个草药
   - 奖励: 100经验值、50金币、3个生命药水

3. **史莱姆狩猎** (支线任务)
   - 目标: 击败5只史莱姆
   - 奖励: 150经验值、75金币、皮甲

4. **古代遗迹** (主线任务)
   - 目标: 探索遗迹并收集水晶碎片
   - 奖励: 300经验值、200金币、钢剑、古老钥匙

#### 使用方法
- 按 `Q` 键打开任务日志
- 与NPC对话接受任务
- 完成任务目标自动更新进度
- 返回NPC处交任务获得奖励

### ⚔️ 战斗系统 (Combat System)

#### 功能特点
- **回合制战斗**: 基于速度的战斗顺序
- **伤害计算**: 考虑攻击力、防御力、等级差异
- **暴击系统**: 基于等级的暴击率计算
- **战斗范围**: 32像素的攻击范围
- **敌人AI**: 简单的追踪和攻击AI

#### 战斗机制
- **攻击冷却**: 1秒攻击冷却时间
- **伤害公式**: `伤害 = max(1, 攻击力 - 防御力) * 等级修正 * 随机波动`
- **暴击伤害**: 暴击时伤害提升50%
- **经验奖励**: 击败敌人获得经验值 = 敌人等级 × 10
- **金币奖励**: 击败敌人获得金币 = 敌人等级 × 5 + 随机值

#### 敌人类型
- **史莱姆**: 基础敌人，生命值30，攻击力8，防御力2
- 更多敌人类型可在 `GameDataManager` 中配置

#### 使用方法
- 按 `回车键` 进行攻击
- 面向敌人方向进行攻击
- 击败敌人获得经验和金币
- 高等级敌人可能掉落物品

### 🎯 等级系统 (Level System)

#### 功能特点
- **经验获取**: 完成任务和击败敌人获得经验
- **等级提升**: 每级需要经验 = 当前等级 × 100
- **属性成长**: 升级时自动提升各项属性
- **技能解锁**: 高等级解锁更多功能和装备

#### 属性成长
- **生命值**: 每级 +20 最大生命值
- **攻击力**: 每级 +2 攻击力
- **防御力**: 每级 +1 防御力
- **暴击率**: 基础5%，每级 +1%

### 🗺️ 地图系统 (Map System)

#### 功能特点
- **瓦片地图**: 基于GridEngine的瓦片地图系统
- **碰撞检测**: 精确的碰撞检测和路径寻找
- **NPC分布**: 地图上分布各种NPC
- **物品分布**: 地图上随机分布可收集物品
- **敌人巡逻**: 敌人在地图上巡逻和追踪玩家

#### 地图元素
- **草地**: 可通行区域
- **墙壁**: 不可通行的障碍物
- **建筑**: 装饰性建筑元素
- **传送点**: 地图间的传送功能（待实现）

### 🎨 用户界面 (UI System)

#### 功能特点
- **响应式设计**: 适配桌面和移动设备
- **标签页界面**: 状态、背包、任务、战斗四个标签页
- **实时更新**: 游戏状态实时反映在UI中
- **快捷键支持**: 键盘快捷键操作
- **触摸优化**: 移动设备触摸操作优化

#### 界面组件
1. **状态栏**: 显示等级、经验、生命值、金币
2. **背包界面**: 物品管理、装备显示、物品详情
3. **任务日志**: 活跃任务、完成进度、任务描述
4. **战斗信息**: 战斗状态、战斗历史、伤害记录

#### 快捷键
- `I`: 打开背包
- `Q`: 打开任务日志
- `C`: 打开战斗信息
- `ESC`: 关闭UI界面

### 💾 存档系统 (Save System)

#### 功能特点
- **自动存档**: 游戏状态自动保存到本地存储
- **数据持久化**: 玩家进度、背包、任务、战斗数据
- **存档恢复**: 重新加载游戏时恢复所有数据
- **数据安全**: 错误处理和存档验证

#### 存档内容
- 玩家状态（等级、经验、属性）
- 背包内容（物品、装备）
- 任务进度（活跃任务、完成状态）
- 游戏位置（当前地图、坐标）

## 🎮 游戏玩法

### 基础操作
1. **移动**: 使用 WASD 或方向键移动角色
2. **交互**: 按空格键与NPC对话或收集物品
3. **攻击**: 按回车键攻击敌人
4. **背包**: 按 I 键打开背包管理
5. **任务**: 按 Q 键查看任务进度

### 游戏流程
1. **开始游戏**: 点击"开始冒险"按钮
2. **接受任务**: 与NPC对话接受任务
3. **完成任务**: 在地图上完成任务目标
4. **获得奖励**: 返回NPC处交任务获得奖励
5. **升级成长**: 积累经验值提升等级
6. **探索世界**: 发现新的区域和任务

### 进阶技巧
- **物品管理**: 合理使用背包空间，优先收集任务物品
- **战斗策略**: 利用地形优势，避免被多个敌人包围
- **任务规划**: 同时进行多个任务，提高效率
- **装备搭配**: 根据战斗需求选择合适的装备

## 🔧 开发指南

### 添加新物品
1. 在 `GameDataManager.ts` 的 `initializeItems()` 方法中添加物品定义
2. 设置物品属性：类型、图标、效果、稀有度等
3. 在地图上添加物品生成逻辑

### 添加新任务
1. 在 `GameDataManager.ts` 的 `initializeQuests()` 方法中添加任务定义
2. 设置任务目标、奖励、前置条件等
3. 在NPC数据中关联任务

### 添加新敌人
1. 在 `EnhancedGameScene.ts` 的 `createEnemies()` 方法中添加敌人生成逻辑
2. 设置敌人属性：生命值、攻击力、防御力等
3. 在战斗系统中处理敌人AI

### 自定义UI
1. 修改 `GameUI.tsx` 中的UI组件
2. 添加新的标签页或功能模块
3. 更新事件处理和数据绑定
