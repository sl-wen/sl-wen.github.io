# 🎮 增强版俯视角RPG游戏

这是一个基于 [Phaser 3](https://phaser.io/) 和 React 的增强版俯视角RPG游戏，参考了 [top-down-react-phaser-game](https://github.com/blopa/top-down-react-phaser-game) 项目的实现，并添加了大量新功能和系统。

## ✨ 核心功能

### 🎯 基础功能
- **玩家移动**: 使用 WASD 或方向键控制角色移动
- **NPC交互**: 与NPC对话系统，接受和完成任务
- **地图系统**: 瓦片地图和碰撞检测
- **相机跟随**: 平滑的相机跟随系统
- **物理系统**: 基于Phaser Arcade物理引擎

### 🎒 物品系统
- **背包管理**: 20个槽位的背包系统
- **物品分类**: 武器、护甲、消耗品、材料、任务物品
- **堆叠系统**: 支持物品堆叠，提高背包效率
- **装备系统**: 武器、护甲、饰品三个装备槽位
- **物品效果**: 消耗品提供临时或永久属性加成

### 📋 任务系统
- **任务类型**: 主线任务、支线任务、日常任务、周常任务
- **任务目标**: 击杀、收集、对话、探索等多种目标类型
- **任务链**: 支持前置任务和任务依赖关系
- **进度跟踪**: 实时显示任务完成进度
- **奖励系统**: 经验值、金币、物品奖励

### ⚔️ 战斗系统
- **回合制战斗**: 基于速度的战斗顺序
- **伤害计算**: 考虑攻击力、防御力、等级差异
- **暴击系统**: 基于等级的暴击率计算
- **战斗范围**: 32像素的攻击范围
- **敌人AI**: 简单的追踪和攻击AI

### 🎯 等级系统
- **经验获取**: 完成任务和击败敌人获得经验
- **等级提升**: 每级需要经验 = 当前等级 × 100
- **属性成长**: 升级时自动提升各项属性
- **技能解锁**: 高等级解锁更多功能和装备

### 🎨 用户界面
- **响应式设计**: 适配桌面和移动设备
- **标签页界面**: 状态、背包、任务、战斗四个标签页
- **实时更新**: 游戏状态实时反映在UI中
- **快捷键支持**: 键盘快捷键操作
- **触摸优化**: 移动设备触摸操作优化

### 💾 存档系统
- **自动存档**: 游戏状态自动保存到本地存储
- **数据持久化**: 玩家进度、背包、任务、战斗数据
- **存档恢复**: 重新加载游戏时恢复所有数据
- **数据安全**: 错误处理和存档验证

## 🎮 游戏元素

### 玩家角色
- **绿色方块**: 玩家角色（可替换为精灵动画）
- **属性系统**: 生命值、攻击力、防御力、速度、等级
- **装备系统**: 武器、护甲、饰品装备槽位
- **背包系统**: 20个物品槽位

### NPC角色
- **村长**: 主线任务发布者
- **草药师**: 收集任务发布者
- **守卫**: 战斗任务发布者
- **学者**: 探索任务发布者

### 敌人类型
- **史莱姆**: 基础敌人，生命值30，攻击力8，防御力2
- 更多敌人类型可在配置中添加

### 物品类型
- **武器**: 木剑、铁剑、钢剑等，提供攻击力加成
- **护甲**: 皮甲、铁甲等，提供防御力和生命值加成
- **消耗品**: 生命药水、魔法药水、力量药水等
- **材料**: 草药、铁矿、金矿等，用于制作和任务
- **任务物品**: 古老钥匙、水晶碎片等特殊物品

### 地图瓦片
- **浅绿色**: 草地（可通行）
- **棕色**: 墙（不可通行）
- **灰色**: 建筑1
- **蓝色**: 建筑2

## 🎮 控制说明

### 基础控制
- **WASD / 方向键**: 移动角色
- **空格键**: 与NPC对话或收集物品
- **回车键**: 攻击敌人
- **ESC键**: 关闭UI界面

### 界面快捷键
- **I键**: 打开背包界面
- **Q键**: 打开任务日志
- **C键**: 打开战斗信息

### 移动端控制
- **触摸移动**: 虚拟摇杆或点击移动
- **触摸交互**: 点击NPC或物品进行交互
- **手势操作**: 支持滑动和点击手势

## 🚀 游戏玩法

### 基础流程
1. **开始游戏**: 点击"开始冒险"按钮
2. **接受任务**: 与NPC对话接受任务
3. **完成任务**: 在地图上完成任务目标
4. **获得奖励**: 返回NPC处交任务获得奖励
5. **升级成长**: 积累经验值提升等级
6. **探索世界**: 发现新的区域和任务

### 进阶技巧
- **物品管理**: 合理使用背包空间，优先收集任务物品
- **战斗策略**: 利用地形优势，避免被多个敌人包围
- **任务规划**: 同时进行多个任务，提高效率
- **装备搭配**: 根据战斗需求选择合适的装备
