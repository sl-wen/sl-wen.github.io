# 音频文件说明

这个目录应该包含以下音频文件：

## 背景音乐 (BGM)
- `bgm_menu.mp3` - 主菜单背景音乐
- `bgm_village.mp3` - 村庄背景音乐
- `bgm_forest.mp3` - 森林背景音乐
- `bgm_cave.mp3` - 洞穴背景音乐
- `bgm_battle.mp3` - 战斗背景音乐

## 音效 (SFX)
- `sfx_move.mp3` - 移动音效
- `sfx_attack.mp3` - 攻击音效
- `sfx_pickup.mp3` - 拾取音效
- `sfx_damage.mp3` - 受伤音效
- `sfx_levelup.mp3` - 升级音效
- `sfx_ui_click.mp3` - UI点击音效
- `sfx_ui_hover.mp3` - UI悬停音效

## 临时解决方案
由于音频文件暂时缺失，游戏会静音运行。请添加相应的音频文件以启用完整的音频体验。

## 音频格式要求
- 格式: MP3
- 采样率: 44.1kHz
- 位深度: 16bit
- 声道: 单声道或立体声
